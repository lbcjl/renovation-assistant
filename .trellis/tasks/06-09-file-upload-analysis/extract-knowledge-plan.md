## 处理策略

### 文本内容
- 使用 Playwright 访问每个链接
- 提取完整文本内容
- 保存为 Markdown 格式

### 图片内容
- 截取完整页面截图
- 提取页面中的独立图片
- 对于表格、图表类图片，考虑 OCR 识别
- 保存到 backend/data/knowledge/images/ 目录

### 输出格式
每个主题生成一个 .md 文件：
- 文件名：英文slug格式
- 内容：标题 + 正文 + 图片引用
- 图片：保存在同名文件夹下
