# 文件上传分析功能

## Goal
为装修助手添加文件上传功能，用户可以上传各种类型的文件（图片、文档、表格等），系统能够分析文件内容并提供相关的装修建议或信息提取。

## Requirements (Evolving)

### Confirmed
- **文件类型支持**: 多种类型
  - 图片文件（装修效果图、户型图等）
  - 文档文件（装修合同、报价单等PDF/Word）
  - 表格文件（预算清单Excel等）

### Confirmed (continued)
- **分析功能**: 智能问答
  - 用户上传文件后，可以针对文件内容提问
  - 系统理解文件内容并回答相关问题
  - 例如：上传户型图后问"这个户型适合什么风格？"
  - 例如：上传报价单后问"这个报价合理吗？"

- **用户交互流程**: 先上传，后提问
  - 用户先通过上传界面选择并上传文件
  - 上传成功后，文件作为对话上下文
  - 用户在聊天界面中针对文件内容提问
  - 系统回答时可以引用文件内容

- **文件管理模式**: 持久模式
  - 文件上传后持久保存到文件库
  - 用户可以查看、管理已上传的文件
  - 支持跨会话引用（下次打开应用仍可访问之前上传的文件）
  - 用户可以选择某个文件加入当前对话上下文
  - 用户可以删除不需要的文件

- **文件处理方式**: 混合模式
  - 默认：文件通过 LLM 的 vision/document 能力直接理解（临时处理）
  - 可选：用户可以将重要文件标记并加入 RAG 知识库
  - 入库文件：内容被向量化，与现有知识库一起检索，可跨会话使用
  - 未入库文件：仅在当前对话上下文中可用

- **上传界面设计**: 聊天输入框集成
  - 在聊天输入框旁边添加上传按钮（类似"+"图标）
  - 点击后弹出文件选择器，支持多选
  - 上传成功后在聊天区域显示文件卡片
  - 文件卡片显示：文件名、类型、大小、预览（图片）、操作按钮

- **技术实现细节**:
  - **文件大小限制**: 图片 10MB，文档 20MB，表格 10MB
  - **元数据存储**: JSON 文件（与现有项目风格一致）
  - **多文件上传**: 支持一次选择多个文件上传
  - **存储路径**: `backend/data/uploads/{timestamp}_{random_id}.{ext}`

## Technical Notes

### 架构设计
```
Frontend (React):
  - ChatInput component: 添加上传按钮
  - FileUpload component: 处理文件选择和上传
  - FileCard component: 显示文件卡片
  - FileList component: 文件管理列表

Backend (FastAPI):
  - app/api/files.py: 文件上传和管理 API
  - app/services/file_service.py: 文件处理逻辑
  - app/rag/file_processor.py: 文件内容提取和向量化
  - backend/data/uploads/: 文件存储目录
  - backend/data/file_metadata.json: 文件元数据存储
```

### 文件处理流程
1. 前端选择文件 → 验证大小/类型 → 显示上传进度
2. 后端接收文件 → 保存到磁盘 → 生成元数据 → 返回文件信息
3. 用户提问 → 系统识别相关文件 → 提取内容 → 传递给 LLM
4. 用户选择"加入知识库" → 内容提取 → 分块 → 向量化 → 存入 RAG

### LLM 集成
- 图片：使用支持 vision 的模型（如 GPT-4V, Claude 3）直接理解
- PDF/Word：提取文本后作为上下文传递给 LLM
- Excel/CSV：解析为表格数据，格式化后传递给 LLM
