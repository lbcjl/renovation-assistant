# 门窗

## 窗户选什么材质？

### 断桥铝窗
**主流推荐**，综合性能最优：隔热保温、隔音、密封性好、不易变形、免维护。"断桥"指铝型材中间用隔热条（PA66 尼龙）断开内外铝材，阻断热传导。

- **型号**：数字表示型材宽度，如 60 系列（6cm 宽）、70 系列（7cm 宽）。数字越大保温隔音越好，但价格越高；普通住宅 60-70 系列够用，寒冷地区或临街吵闹推荐 ≥70。
- **玻璃**：标配中空双层玻璃（5+12A+5，即两片 5mm 玻璃 + 12mm 空气层），隔音保温；临街噪音大可升级三层中空或夹胶玻璃。
- **五金**：进口品牌（如德国好博、丝吉利娅）更耐用，开关顺滑、密封好；国产选知名品牌。
- **价格**：按平方算，含型材、玻璃、五金、安装，普通 60 系列约 400-600 元/㎡，70 系列约 600-900 元/㎡（各地差异大）。

### 塑钢窗
价格便宜、保温尚可，但易老化变色、强度差、寿命短（5-10 年）；新房装修不推荐，老旧小区低预算可考虑。

### 铝合金窗（非断桥）
导热快、保温差，南方温差小地区或阳台封窗可用，但隔音弱于断桥铝。

### 实木窗
颜值高、环保，但价格贵、需定期保养防开裂变形，适合别墅或特殊风格。

**结论**：预算允许优选断桥铝 ≥60 系列 + 中空玻璃 + 品牌五金。

## 窗户开启方式怎么选？

- **平开窗**（内开/外开）：密封性、隔音最好，通风面积大；外开不占室内空间，内开擦玻璃方便但占空间（可装内开内倒五金兼顾）。
- **推拉窗**：不占室内空间、开关轻便，但密封性略逊平开窗、通风面积只有一半。
- **固定窗**：不开启，用于采光或大落地窗的某几扇；成本最低、密封性最好。

选择：卧室、客厅推荐平开（内开内倒），密封隔音好；阳台、厨房可用推拉，节省空间。

## 窗户隔音怎么做？

噪音大（临街、高架、机场）必须重视隔音：

- **玻璃升级**：
  - 中空玻璃（5+12A+5）：阻隔中高频噪音（说话声、鸟叫），基础隔音。
  - 夹胶玻璃（PVB 膜）：阻隔中低频（车流、发动机），隔音更强；可做夹胶中空（5 夹胶 +12A+5）最优。
  - 三层中空：性价比低于夹胶中空，不首选。
- **密封条**：三元乙丙橡胶（EPDM）或汽车级密封条，老化慢、弹性好；定期检查更换。
- **开启方式**：平开窗 > 推拉窗（平开密封更严）。
- **安装**：窗框与墙体缝隙用发泡胶 + 密封胶填充严实，避免漏声。

**降噪方案**：临街楼层选断桥铝 ≥70 系列 + 夹胶中空玻璃 + 平开窗 + 优质密封条，可降噪 30-40 分贝。

## 入户门和室内门怎么选？

### 入户门（防盗门）
- **等级**：国标分甲乙丙丁四级，甲级防盗性能最强（防破坏时间 ≥30 分钟）；家用选甲级或乙级。
- **门板厚度**：≥0.8mm 钢板（甲级标准），锁点 ≥12 个，锁芯选 C 级（最难技术开启）。
- **填充物**：铝蜂窝或岩棉，保温隔音；避免纸壳填充。
- **品牌**：盼盼、步阳、王力、美心等知名品牌，质保与售后有保障。

### 室内门
- **实木门**：全实木或实木指接，质感最好、环保、隔音强，但价格高（2000-5000 元/樘起）、需防潮防变形。
- **实木复合门**：实木框架 + 密度板/实木皮，性价比高（800-2000 元/樘）、款式多、较稳定，是家用主流。
- **模压门**：密度板模压成型 + 贴皮，最便宜（300-800 元/樘），但不耐磨、隔音差、易变形；出租房或储藏室可用。
- **谷仓门/吊轨门**：颜值高、省空间（不占开门区域），但密封隔音差，不适合卧室卫生间。

**建议**：卧室卫生间选实木复合门（隔音、质感、性价比平衡）；书房、衣帽间可选谷仓门；预算充足选实木门。

### 门锁与五金
- **门锁**：入户门用 C 级锁芯；室内门锁普通执手锁够用，卫生间带内锁、卧室可选静音锁。
- **合页**：不锈钢或铜质，≥3 个/门，承重好、不异响；门重（实木门）需加厚加宽合页。
- **门吸**：防门撞墙，墙吸或地吸按需选。

## 门窗安装要注意什么？

- **测量**：窗户拆旧后复测洞口尺寸，留安装缝隙（四周 1-2cm）。
- **固定**：窗框用膨胀螺栓固定，间距 ≤60cm，确保牢固。
- **发泡与打胶**：窗框与墙体缝隙先打发泡胶（九分满，留膨胀空间）、外侧打密封胶（防水），内侧可贴密封条。室外打结构胶防雨水渗入。
- **窗台石/泄水孔**：窗台石向外倾斜 5°，防雨水倒灌；窗框下方留泄水孔（孔口向外、有盖防堵）。
- **验收**：检查开关顺畅、密封条无翘起、玻璃无划痕气泡、五金件灵活、打胶平整。

## 阳台要不要封窗？

**封窗优点**：防尘防雨、隔音保温、多一间储物/洗衣/休闲区、防小孩宠物坠落。  
**不封优点**：通风采光更好、晾衣方便、不违建（部分小区封阳台算违建或需物业审批）。

**建议**：
- 低楼层、临街、风沙大、有小孩宠物 → 建议封。
- 高层、安静小区、阳台大 → 可部分封（生活阳台封、观景阳台留开放）。
- 封窗前确认物业规定、外立面统一要求。
