# 预算与报价

## 装修预算大概怎么估？

装修花费受城市、面积、档次、风格影响很大，没有统一标准。常见做法是按「基础装修 + 主材 + 家具家电 + 软装」分块估算，并预留 10%–20% 的机动费用应对增项。建议先定总预算上限，再按比例分配到各块，避免某一项超支挤占其他部分。

## 半包和全包有什么区别？

- 半包：施工方负责人工和辅料（水泥、沙子、电线等），业主自购主材（瓷砖、地板、洁具、橱柜等）。主材质量可控，但需自己花精力选购。
- 全包（包工包料）：人工、辅料、主材都由施工方负责，省心；但一定要在合同里写清主材的品牌、型号、档次，防止以次充好。

选哪种取决于你的时间精力，以及对主材品质的把控意愿。

## 报价单里常见的坑有哪些？

- 漏项：故意少报项目，施工中再以「增项」加价。
- 模糊计量：单位、面积算法不清，结算时虚增工程量。
- 材料含糊：只写「乳胶漆」却不写品牌、型号、档次。

应对：要求报价单逐项清晰（项目、单位、单价、数量、材料品牌型号），并在合同中约定增项规则与上限。
