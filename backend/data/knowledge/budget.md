# 预算与报价

## 装修预算大概怎么估？

装修花费受城市、面积、档次、风格影响很大，没有统一标准。常见做法是按「基础装修 + 主材 + 家具家电 + 软装」分块估算，并预留 10%–20% 的机动费用应对增项。建议先定总预算上限，再按比例分配到各块，避免某一项超支挤占其他部分。

## 半包和全包有什么区别？

- 半包：施工方负责人工和辅料（水泥、沙子、电线等），业主自购主材（瓷砖、地板、洁具、橱柜等）。主材质量可控，但需自己花精力选购。
- 全包（包工包料）：人工、辅料、主材都由施工方负责，省心；但一定要在合同里写清主材的品牌、型号、档次，防止以次充好。

选哪种取决于你的时间精力，以及对主材品质的把控意愿。

## 报价单里常见的坑有哪些？

- 漏项：故意少报项目，施工中再以「增项」加价。
- 模糊计量：单位、面积算法不清，结算时虚增工程量。
- 材料含糊：只写「乳胶漆」却不写品牌、型号、档次。

应对：要求报价单逐项清晰（项目、单位、单价、数量、材料品牌型号），并在合同中约定增项规则与上限。

## 装修各项费用占比怎么分配？

参考比例（仅供参考，实际按需调整）：

- **基础装修（硬装）**：30%-40%（水电改造、防水、吊顶、墙面地面处理、木工等人工+辅料）
- **主材**：30%-35%（瓷砖、地板、门窗、橱柜、洁具、五金等）
- **家具家电**：20%-25%（沙发、床、餐桌、冰箱、空调、洗衣机等）
- **软装**：5%-10%（窗帘、灯具、装饰画、绿植等）
- **机动/预留**：10%-15%（应对增项、返工、升级）

示例：总预算 20 万，可分配为硬装 6-8 万、主材 6-7 万、家具家电 4-5 万、软装 1-2 万、预留 2-3 万。

## 怎么控制预算不超支？

1. **先定总预算天花板**：按能承受的上限定，别想着"边装边加"。
2. **分项目记账**：用 Excel 或记账 App 记录每笔支出（类别、金额、实际 vs 预算），超支项目及时调整其他项目。
3. **主材提前选定**：开工前把瓷砖、地板、橱柜、洁具等定好并锁价，避免施工中临时选、容易冲动消费。
4. **警惕"升级"陷阱**：商家常推"加一点钱升级更好的"，要判断是否真需要，别被话术带着走。
5. **硬装省、软装升**：墙面、水电等基础工程做好，家具软装可后期慢慢添置、分期购买。
6. **货比三家**：尤其大件（橱柜、定制柜、门窗），多问几家、对比性价比。

## 清包、半包、全包怎么选？

除了半包、全包，还有一种"清包"：

- **清包**：业主自己买全部材料（主材+辅料），只请工人施工。
  - 优点：成本可控到最细、材料质量自己把关。
  - 缺点：极耗时间精力（跑建材市场、算量、协调送货）、需懂行（不懂容易买错/买贵/买少）、出问题工人和材料商互相推责任。
  - 适合人群：时间充足、懂装修、愿意深度参与的 DIY 爱好者或预算极紧的自建房。

**选择建议**：
- 上班族、装修小白 → **半包或全包**（全包省心但要盯紧合同）。
- 时间多、想省钱、愿意学习 → **半包**（主材自己买）。
- 极有经验或极省钱 → **清包**（不建议首次装修者尝试）。

## 装修贷款划算吗？

装修贷是银行针对装修场景的消费贷款，利率通常比信用卡分期低、比房贷高。

**优点**：
- 缓解资金压力，避免一次性掏空积蓄。
- 利率相对较低（年化约 3%-6%，各银行不同）。

**缺点**：
- 有利息成本；若提前还款可能有手续费。
- 部分银行要求贷款打到装修公司账户、或需提供装修合同，限制资金用途。

**建议**：
- 预算紧、但有稳定收入 → 可考虑，算好总利息在可承受范围内。
- 能付全款 → 不建议贷款，省利息。
- 比较各银行利率、还款方式、提前还款政策，选最优方案。
