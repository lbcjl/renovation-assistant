# 卫生间装修

## 卫生间干湿分离怎么做？

干湿分离能让洗澡时水蒸气、积水不影响马桶、洗手台区域，保持干爽、减少滑倒风险、延长电器寿命。

常见方案：
- **玻璃淋浴房**：最彻底的分离，适合面积 ≥5㎡ 的卫生间。选钢化玻璃（带 3C 认证）、厚度 ≥6mm、五金件优质不易生锈。
- **浴帘**：最省钱灵活，适合小卫生间。缺点是密封性一般、需定期清洗防霉。
- **半墙 + 玻璃/浴帘**：砌半堵墙（高约 1.2m）挡水，上方装玻璃或挂浴帘，兼顾隔水与通透。
- **三分离/四分离**：大卫生间可将淋浴、马桶、洗手台各自独立（三分离），或再分出洗衣区（四分离），多人使用不冲突。

注意：淋浴区地面要有挡水条或做下沉 1-2cm，地漏坡度足够快速排水。

## 卫生间用什么瓷砖？

- **墙砖**：釉面砖为主，防水不吸污、好打理；规格常见 300×600mm 或 300×450mm。
- **地砖**：必须防滑，选哑光面或带纹理的；规格常用 300×300mm 小砖，便于做坡度。
- **通铺大砖**：颜值高、接缝少，但对工人技术和找坡要求高，且大砖自重大需确认墙体承重。
- **花砖/美缝**：可做局部点缀（如淋浴背景墙），美缝剂选防水防霉的。

关键：地砖防滑 > 颜值；墙地砖留缝贴、做美缝防渗水发霉。

## 卫生间通风怎么解决？

- **有窗户**：优先自然通风，窗户尽量常开或装百叶保持气流；洗澡时配合排气扇加速排湿。
- **无窗户（暗卫）**：必装排气扇/换气扇，建议装在吊顶上靠近淋浴区，风量选 ≥300m³/h；每次洗澡后开 20-30 分钟排湿气。
- **管道排风**：若能接公共排风道（需物业确认），效果优于单排气扇。
- **防潮**：暗卫易返潮发霉，墙面建议通体防水（至少做到顶板下沿）、装浴霸带烘干功能、不放木质家具。

## 马桶、花洒、浴室柜怎么选？

### 马桶
- **冲水方式**：虹吸式静音、冲净效果好，主流推荐；直冲式冲力大但噪音稍大。
- **即热式智能马桶盖**：不需储热水箱、体积小，适合小卫生间；储热式便宜但预热慢。
- **排水方式**：地排（下排）最常见；墙排（后排）美观但改造成本高，需确认排水口位置。

### 花洒
- **恒温花洒**：自动调节水温，防烫防冷，体验好；预算允许建议选。
- **顶喷 + 手持**：顶喷（直径 20-25cm）洗澡舒适，手持冲地、冲浴缸灵活，两者都要。
- **材质**：全铜阀芯 + 不锈钢/铜主体，耐用不生锈。

### 浴室柜
- **材质**：PVC 或橡木（需做防水处理）；实木不推荐（易变形）。
- **台盆**：台下盆好打理（台面水直接扫入盆）；台上盆颜值高但易积水藏污。
- **收纳**：镜柜 + 下柜组合，小卫生间必备；预留插座给吹风机、电动牙刷。

## 卫生间装修常见坑

- **防水没做好**：墙面防水淋浴区做到 1.8m、其他区域 30cm，地面全做；做完闭水试验 48 小时确认不漏。
- **地漏排水慢**：地面坡度不够或地漏堵塞。安装时确保坡向地漏、地漏选深水封防臭款。
- **插座不够/位置不对**：马桶旁需预留智能马桶盖插座、镜柜旁需多个插座、浴霸/排气扇需单独电路；全部带防溅盒。
- **吊顶材料选错**：卫生间湿气重，必须用铝扣板或防水石膏板，木质吊顶会发霉变形。
- **热水器位置不当**：电热水器重，墙体需承重墙或加固；燃气热水器需通风良好、有燃气管道的位置；装在离淋浴近的地方减少热水管线损耗。
