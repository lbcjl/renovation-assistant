# 选材与环保

## 装修怎么减少甲醛等污染？

甲醛主要来自人造板材（柜体、家具）、胶黏剂、部分布艺。要点：

- 选用环保等级更高的板材（如达到 E0／ENF 级别的更优），并关注总用量——板材越多，叠加释放越高。
- 减少不必要的全屋定制堆砌，注意污染的「叠加效应」。
- 选用合规的胶黏剂、乳胶漆等辅料。
- 装修后充分通风（数周至数月）；有条件可做检测/治理，达标后再入住。孕妇、婴幼儿家庭尤其要谨慎。

## 乳胶漆怎么选？

关注环保指标（VOC、甲醛、APEO 等）、遮盖力与耐擦洗性。底漆 + 面漆配套使用，面漆按需刷 2 遍。注意施工时的兑水比例与环境湿度。颜色建议先看大色卡或小面积试刷——墙面大面积上墙后，颜色通常比色卡看起来更深、更显。
