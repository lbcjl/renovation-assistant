# 吊顶

## 吊顶用石膏板还是铝扣板？

吊顶主要用来遮挡梁、管线、中央空调/新风等设备，并做造型、丰富层次。

- 石膏板：可塑性强、能做各种造型、整体平整美观，适合客厅、卧室等干区，也适合开放式厨房与客厅做统一造型。缺点是较脆、承重差（重物需在顶面加固）、受潮易开裂、不耐油烟、拆改后难复原。
- 铝扣板：防水、防火、耐脏、易擦洗，且可逐块拆卸、检修方便，是厨房、卫生间吊顶的主流选择。缺点是块小接缝多、花色有限、整体美观一般。
- 集成吊顶：不是单一材料，而是「扣板 + 龙骨 + 电器模块（照明/换气/取暖）」的组合系统；厨卫常用的「铝扣板集成吊顶」即属此类。预算充足、追求颜值可考虑蜂窝大板（接缝少、整体性强）。

经验结论：封闭式厨卫优先铝扣板/集成吊顶（防潮耐脏、好检修）；客厅卧室及开放式空间用石膏板更美观。

## 吊顶安装要注意什么？

- 先做后封：装吊顶前先把烟道、水电线路、设备管线安装到位，最后再封板。
- 重物加固：排气扇、浴霸、灯具等不要直接挂在扣板或龙骨上，应固定到顶面结构，避免吊顶变形；铝扣板吊顶也不宜装超重吊灯。
- 打孔：按图纸定位打孔，深度不宜过大，避免打到墙顶内的管线。
- 留检修口：厨卫顶部走水电，务必预留检修口方便日后维修。
- 厨卫若坚持用石膏板：要用耐水石膏板并做好防水防锈、留检修口；通风差的厨卫仍不建议。
