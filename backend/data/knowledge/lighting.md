# 照明设计

## 家庭照明怎么布局？

传统"一房一灯"已过时，现代照明讲究分层：**基础照明 + 重点照明 + 氛围照明**。

### 基础照明（主光源）
提供整体亮度，让人能正常活动。

- **客厅/卧室**：吸顶灯、筒灯均布、或无主灯设计（多个筒灯/射灯组合）。
- **厨房/卫生间**：吸顶灯或集成吊顶灯（防水防雾）。
- **走廊/玄关**：筒灯或吸顶灯，间距 1.5-2m。

### 重点照明（功能光源）
照亮特定区域，满足阅读、做饭、化妆等任务。

- **厨房操作台**：橱柜下方装灯带或 T5/T8 灯管，避免切菜时背光。
- **书桌/床头**：台灯或壁灯，照度 ≥500 lux，护眼不刺眼。
- **卫生间镜前**：镜前灯（左右 + 上方打光最佳），化妆不留阴影。
- **衣柜内**：感应灯带，开门自动亮。

### 氛围照明（装饰光源）
营造情绪、突出装饰。

- **灯带**：吊顶、电视墙、床底、楼梯踢脚；可调光调色（RGB）。
- **射灯/轨道灯**：照亮挂画、摆件、电视墙。
- **落地灯/台灯**：沙发旁、床头柜，温馨柔和。

**原则**：基础照明保证亮度，重点照明提升效率，氛围照明加分不强求。

## 色温怎么选？

色温单位是**开尔文（K）**，影响光的"冷暖"感觉：

- **2700-3000K（暖白）**：偏黄，温馨放松，适合卧室、客厅氛围灯、餐厅。
- **4000-4500K（自然白/中性白）**：接近日光，明亮舒适，适合客厅主灯、书房、走廊。
- **5000-6500K（冷白）**：偏蓝白，清爽提神，适合厨房、卫生间、办公区。

**建议**：
- 客厅主灯 4000K，氛围灯 3000K；卧室全用 3000K 助眠；厨卫 5000K 显色好；书房阅读 4000-5000K 专注不困。
- 不确定时选 **4000K 中性白**，适配性最强。

## 无主灯设计值得做吗？

**无主灯 = 取消大吊灯/吸顶灯，用筒灯、射灯、灯带组合**，灵活分区照明、层次丰富、简洁现代。

**优点**：
- 不压层高（筒灯嵌入吊顶，适合层高 ≤2.7m 的房间）。
- 照明均匀，无明显明暗分界。
- 灯具可分组控制，场景多变（看电视调暗、看书调亮）。

**缺点**：
- 前期设计复杂，需提前规划灯位、回路、开关。
- 成本高：吊顶 + 多个筒灯/射灯 + 智能开关，比单个主灯贵 30%-50%。
- 后期维修麻烦（嵌入式灯具需拆吊顶）。

**适合人群**：追求设计感、预算充足、层高偏低、接受智能家居的年轻家庭。

**不适合**：预算紧、层高够用、喜欢传统大气吊灯、懒得规划的家庭 → 直接主灯 + 辅助光源更省心。

## 智能照明要不要装？

智能照明 = 用手机/语音/传感器控制开关、亮度、色温、场景。

**入门方案（低成本）**：
- 换智能灯泡（如米家、欧瑞博），单个 50-200 元，支持调光调色、定时、语音。
- 装智能开关（零火/单火线），改造现有灯具，100-300 元/个。

**进阶方案（全屋智能）**：
- 全屋智能开关 + 中控屏 + 网关，统一品牌生态（米家、欧瑞博、Aqara 等）。
- 配传感器（人体、光线），实现"回家自动开灯""天黑自动开灯""无人自动关灯"。
- 设置场景模式："观影模式"关主灯开氛围灯、"睡眠模式"全关、"起夜模式"床底灯带微亮。

**建议**：
- 尝鲜先买几个智能灯泡装卧室/客厅，好用再扩展。
- 新房装修直接布零火线、预留智能开关位，后期升级方便。
- 品牌选兼容性好的（支持 HomeKit、天猫精灵、小爱同学等），避免生态孤岛。

## 灯具怎么选不踩坑？

### 看参数
- **流明（lm）**：衡量亮度，数值越高越亮；客厅 15-20㎡ 需 2000-3000lm，卧室 10-15㎡ 需 1000-1500lm。
- **显色指数（CRI/Ra）**：显色真实度，≥80 够用，≥90 优秀（化妆镜、画作照明推荐 ≥90）。
- **频闪**：劣质灯频闪伤眼，选无频闪或通过 CCC/CQC 认证的产品。

### 看安装
- **嵌入式筒灯/射灯**：需吊顶，开孔尺寸提前确认（常见 7.5cm、9cm、12cm），预留 10cm 以上吊顶深度。
- **吸顶灯/吊灯**：确认承重（吊顶龙骨或顶板需加固），大吊灯 >5kg 需打膨胀螺栓。
- **灯带**：选 12V/24V 低压灯带（安全）+ 配套电源，每 5m 一个电源；藏灯槽宽度 ≥5cm。

### 看品牌与售后
- 大品牌：飞利浦、欧普、雷士、三雄极光、松下，质保 2-3 年。
- 避免杂牌：便宜但寿命短、频闪、显色差。

## 照明常见坑

- **只装主灯**：亮是亮了，但无层次、刺眼；沙发看书、厨房切菜背光看不清。
- **色温不统一**：同一空间灯色温不一致（主灯冷白、台灯暖白），看着别扭。
- **开关位置不合理**：卧室门口关灯、床头无开关，睡前要下床关灯；双控开关必装。
- **灯具过时/难清洁**：复杂水晶吊灯积灰难洗、过时风格（欧式大吊灯）十年后审美疲劳；简约耐看、易清洁更实用。
- **忘记调光**：固定亮度的灯不灵活；建议主光源可调光（调光开关或智能灯），适配不同场景。

## 各空间照明要点速查

| 空间 | 基础照明 | 重点照明 | 氛围照明 | 色温建议 |
|------|---------|---------|---------|---------|
| 客厅 | 吸顶灯/筒灯均布 | 沙发旁落地灯 | 电视墙灯带、射灯 | 4000K 主灯 + 3000K 氛围 |
| 卧室 | 吸顶灯/无主灯 | 床头壁灯/台灯 | 床底灯带 | 3000K 全屋 |
| 厨房 | 吸顶灯 | 橱柜下灯带 | 无 | 5000K |
| 卫生间 | 吸顶灯 | 镜前灯 | 无 | 5000K |
| 书房 | 吸顶灯 | 台灯（护眼灯） | 书架射灯 | 4000-5000K |
| 餐厅 | 吊灯（低垂距桌面 70-80cm） | 无 | 墙面射灯 | 3000-4000K |
| 玄关 | 筒灯 | 无 | 鞋柜灯带 | 4000K |
