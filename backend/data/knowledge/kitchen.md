# 厨房

## 厨房台面选什么材质？

- 石英石（人造石）：家用主流。硬度高、耐磨耐高温、致密无孔不渗污、好打理、性价比高；缺点是花色相对少。多数家庭直接选它。
- 不锈钢：抗菌不渗污、耐烫好擦，可与水槽灶台一体定制；缺点是易被尖锐物刮花留痕、花色单一，家用偏工业风。
- 岩板：颜值高、耐磨耐刮耐高温、不渗色，能做造型；缺点是价格高。
- 天然大理石：纹理美但有孔隙易渗色、较脆，长台面易裂，家用厨房不算理想。

按预算选：实用、频繁下厨且预算低 → 不锈钢；注重颜值与性价比 → 石英石；预算充足追求体验 → 岩板。

## 厨房橱柜与动线要注意什么？

- 布局按户型：一字形（小厨房/单人操作）、L 形、U 形；大厨房别用一字形，否则各功能区距离太大。
- 台面高度按使用者身高定，通常操作台约 80–85cm；水槽两侧最好各留 40–60cm 台面，放待洗/已洗的菜。
- 挡水：台面做挡水条、橱柜背面做挡水板并高出台面，防止水渗入柜体导致板材膨胀脱落。
- 水电点位提前规划：量尺时把油烟机、灶具、冰箱、消毒柜、净水器等电器的规格尺寸和插座位置交代清楚。
- 安装顺序：一般「地柜 → 五金 → 台面 → 吊柜 → 灶具电器」；装前清扫并测量地面水平。
- 五金别忽视：铰链、滑轨、阻尼经常开合，质量直接影响耐用度。
